# `sartoriuslib.maintenance`

One-shot port-level helpers for protocol switching, baud changes, and
SBN-address writes — for callers who don't want to hold a full
[`Balance`](devices.md) session. All operations require `confirm=True`.
See [Safety](../safety.md) and [Commands](../commands.md#configuration-commands-balance-methods).

::: sartoriuslib.maintenance
